# Icon attribution

Chart.it ships icon packs under `web/public/icons/`, generated by `tools/icons` from the sources below. Each pack carries its own licence string in `web/public/icons/manifest.json`. The icons remain the property of their owners; they are redistributed here unmodified apart from technical normalisation (editor metadata and fixed sizes removed, ids scoped, whitespace compacted).

## AWS Architecture Icons

- Source: https://aws.amazon.com/architecture/icons/ (asset package `Icon-package_*.zip`; the version is recorded in the manifest).
- Used: Architecture Service Icons, Resource Icons and Architecture Group Icons (SVG, light variants).
- Terms: use is subject to the AWS Architecture Icons terms published on that page and the AWS trademark guidelines. Amazon Web Services, AWS and the AWS logo are trademarks of Amazon.com, Inc. or its affiliates.

## Microsoft Azure icons

- Source: https://learn.microsoft.com/en-us/azure/architecture/icons/ (`Azure_Public_Service_Icons_V*.zip`, SVG).
- Terms: use is subject to the Microsoft terms of use for Azure icons (shipped in the archive as `Microsoft_Terms_of_Use.pdf`). Microsoft and Azure are trademarks of the Microsoft group of companies.

## Google Cloud icons

- Source: https://cloud.google.com/icons (`core-products-icons.zip` and `google-cloud-legacy-icons.zip`, SVG).

## Generic icons

- Original line icons and group badges authored for Chart.it (`tools/icons/generic/`, `tools/icons/extras/`), distributed under the project licence (MIT, see `LICENSE`).

## Fallback source

- If an official source is unavailable at build time, `tools/icons` falls back to the PNG resources of https://github.com/mingrammer/diagrams (MIT licence, Copyright mingrammer). A pack built this way declares `MIT (mingrammer/diagrams)` as its licence in the manifest. The current build uses the official sources for every pack.
