# Changelog

All notable changes are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions are tags of the form `vX.Y.Z`.

## [Unreleased]

### Added

- Single-user mode (`CHARTIT_SINGLE_USER=1`) for running one container locally without sign-in. Every request acts as one built-in user, `/api/v1/me` reports `singleUser`, the account menu hides Sign out, and the API answers only local hosts and the `CHARTIT_BASE_URL` host. Startup refuses to combine it with test auth or OIDC settings.

### Changed

- `docker-compose.yml` runs in single-user mode and publishes the port on `127.0.0.1` only.

## [0.1.0] - 2026-10-26

First release.

### Added

- Single Go binary that serves the JSON API, the OIDC and test-login routes, `/healthz` and `/readyz`, and an embedded React single-page app.
- SQLite storage (`modernc.org/sqlite`, WAL) with goose migrations applied at startup: users, sessions, documents, document versions and shares.
- OIDC sign-in with the authorisation code flow, PKCE, state and nonce, server-side sessions in a 30 day cookie, and a test login (`CHARTIT_ALLOW_TEST_AUTH=1`) that startup refuses to combine with OIDC settings.
- Environment-driven configuration (`CHARTIT_ADDR`, `CHARTIT_DATA_DIR`, `CHARTIT_BASE_URL`, `CHARTIT_SESSION_SECRET`, `CHARTIT_OIDC_ISSUER`, `CHARTIT_OIDC_CLIENT_ID`, `CHARTIT_OIDC_CLIENT_SECRET`, `CHARTIT_OIDC_SCOPES`, `CHARTIT_ALLOW_TEST_AUTH`, `CHARTIT_LOG_LEVEL`, `CHARTIT_MAX_DOCUMENT_BYTES`).
- Document API under `/api/v1`: create, list (search, tag, trash), rename and tag, soft delete and restore, duplicate, content save with optimistic concurrency, thumbnails, version history with restore, share links, and starter templates. Errors are `application/problem+json`, and mutating requests require `X-Requested-With: chartit`.
- Version history: snapshots at most every five minutes and on named saves, 200 per diagram, restore as a new version.
- Read-only share links that can be revoked, served at `/s/<token>`.
- Diagram editor on React Flow: icon, container, shape and text nodes; 22 container kinds for AWS, Azure, GCP, Kubernetes and generic grouping; orthogonal, straight and bezier connectors with markers, labels and waypoints; properties panel; grid, snap, light and dark themes; undo and redo; copy, paste and duplicate; group, order, lock, align and distribute; command palette; keyboard shortcuts.
- Auto layout through ELK in a web worker (layered and orthogonal, two directions, whole diagram or selection), grid-based edge routing, "Tidy edges" and "Reset edge routes".
- Icon packs for AWS, Azure, Google Cloud, Kubernetes and a generic set, generated by `tools/icons` into `web/public/icons` with a manifest, plus [ATTRIBUTION.md](ATTRIBUTION.md).
- Export from the document model to PNG (1x, 2x, 4x), SVG and PDF, JSON export and import, and copy as PNG.
- Dashboard with five starter templates (AWS three-tier, AWS EKS, Azure hub and spoke, GCP GKE, Kubernetes namespace), thumbnails, search, tag filter, sort, rename, duplicate, trash and restore.
- Autosave with conflict detection and a reload or overwrite banner.
- Dockerfile (distroless, non-root, multi-stage), `docker-compose.yml`, and a Helm chart (`charts/chart-it`) with a single replica, `Recreate` strategy, PersistentVolumeClaim, existing-secret support and optional ingress, tested with golden renders.
- Helm chart documentation: a generic Kubernetes deployment guide in the README covering the OCI chart, the required Secret, persistence, ingress, OIDC values and probes.
- GitHub Actions: path-filtered pull request checks (Go, icon tool, web, Helm, Docker, end-to-end), image and chart publishing on merge to `main`, and release publishing on `v*` tags with a Trivy scan.
- Documentation: README, [architecture overview](docs/architecture.md) and architecture decision records in [docs/adr](docs/adr/).
